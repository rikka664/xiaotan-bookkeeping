# 小谭记账 · 手机版（uni-app）

用 uni-app（Vue3）重写的手机版本：一套代码可打安卓安装包（APK）、可跑在浏览器里。

## 功能（与电脑版对齐）

- 记一笔：金额（最多两位小数）、两级分类联动、日期（默认今天）、备注
- 账单：按月/按分类筛选、点账单可修改或删除（删除有确认）、合计
- 统计：本月/今年/全部 总支出 + 分类排行占比
- 导出：CSV 备份（网页版直接下载；手机版存进「下载」目录），Excel/WPS 打开不乱码
- 数据全部存手机本地（uni 本地存储），不联网、不上传

## 目录说明

| 文件/目录 | 作用 |
|---|---|
| pages.json | 页面清单 + 底部三个标签（记一笔/账单/统计） |
| common/categories.js | 两级分类数据（与电脑版同一套） |
| common/data.js | 账本数据层：增删改查、统计、导出（金额用"分"存） |
| pages/record | 记一笔页 |
| pages/bills | 账单列表页 |
| pages/stats | 统计页 |
| pages/edit | 修改账单页 |

## 怎么运行 / 打包

1. HBuilderX 打开本目录（文件 → 打开目录 → 选 mobile 文件夹）
2. 预览：工具栏「运行」→ 运行到浏览器 → Chrome（电脑上先看效果）
3. 真机预览：手机和电脑连同一 WiFi，「运行」→ 运行到手机或模拟器
4. 打安卓安装包 APK：「发行」→ 原生 App-云打包（首次需注册 DCloud 账号，免费）
